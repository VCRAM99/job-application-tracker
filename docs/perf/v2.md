# Performance and accessibility after the V2 wrap-up

Measured on 2026-11-12 with the same script, machine, and dataset as [m6c.md](m6c.md): `scripts/perf/measure.ts` on a production build (`npx tsx e2e/support/serve.ts build`, without the Turnstile test key) against local Supabase. Health tracking was off for the perf user. `npx tsx scripts/perf/compare.ts m6c v2rerun` prints this table.

**Budget: first-load JS no more than 5% above M6c on any route. Met.**
- The largest change is **+0.3 KB (+0.15%) on Login**: the Turnstile helpers and an empty container. Cloudflare's script loads only when `NEXT_PUBLIC_TURNSTILE_SITE_KEY` is set, so this build has no third-party script.
- Every other page is 0.2–0.3 KB smaller, from the dependency upgrades.

**Accessibility: no score went down.** Career stays at 96; every other measured page is at 100.

**Server work is unchanged.**
- **Supabase and auth calls:** the same on every page (2 auth calls per render).
- **Paste-a-job:** it only adds work when used. The new-application page makes one more small query (the saved AI execution mode), and only for users who have fit analysis.

**Lighthouse performance and LCP** moved by −2 to +3 points and −360 to +288 ms, with no consistent direction. TBT dropped on most pages. The first run of this measurement (`v2`) showed the dashboard at 79. That page has no code change in this branch, and a rerun gave 93, the same as M6c. Treat single Lighthouse samples as noisy; the table above is the rerun.
